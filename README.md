# thetiagogil.com

Tiago Gil's portfolio. Next.js (static export), TypeScript, Tailwind 4. English at `/`, Portuguese at `/pt`.

```bash
npm install
npm run dev       # http://localhost:3000
npm run verify    # typecheck, lint, format, tests, build, end-to-end
```

- `CLAUDE.md`: the project in one page (stack, structure, commands, rules).
- `docs/`: the owner, the code style, the design system, the content rules, the plan and the decision log.
- `docs/study/`: the Direction Study, the visual spec (`python3 -m http.server -d docs/study 4410`).
