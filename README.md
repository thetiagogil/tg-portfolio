# thetiagogil.com

Tiago Gil's portfolio. Next.js (static export), TypeScript, Tailwind 4. English at `/`, Portuguese at `/pt`.

```bash
npm install
npm run dev       # http://localhost:3000
npm run verify    # typecheck, lint, tests, build, end-to-end
```

Project context, design system and plan: `CLAUDE.md` and `docs/`.
